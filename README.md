# Cantilever Beam Deflection Analysis — MATLAB vs. SolidWorks FEA

A cantilever beam (fixed at one end, point load at the free end) solved two
ways — numerically in MATLAB and with finite element analysis in SolidWorks
Simulation — to check that the FEA result agrees with the underlying beam
theory.

**Why this project:** validating an FEA result against an independent
calculation is a core FEA/CFD skill — it's how you catch a wrong boundary
condition, bad mesh, or unit error before trusting a simulation for
something that matters. This project demonstrates that workflow on a simple,
verifiable case.

## Problem setup
- Cantilever beam, one end fixed, point load at the free end
- Length: 500 mm | Cross-section: 20 mm × 10 mm rectangular | Material: AISI 1020 Steel
- Load: 100 N at the free end

## Method

**1. MATLAB (`beam.m`)** — implements the Euler-Bernoulli cantilever
deflection formula across 500 points along the beam:

```
δ(x) = P·x²·(3L − x) / (6·E·I)
```

evaluated as an array (`x = linspace(0, 0.5, 500)`) so the full deflection
curve can be plotted, not just the tip value.

**2. SolidWorks Simulation (FEA)** — the same beam modeled, meshed, fixed at
one end, and loaded with 100 N at the free-end face, solved as a static
study.

## Results

| Quantity                  | MATLAB (numerical) | SolidWorks FEA | Analytical (hand calc) |
|-----------------------------|:--------------------:|:----------------:|:-------------------------:|
| Max deflection (mm)        | 12.50                | *pending*         | 12.50                     |
| Max bending stress (MPa)   |    pending                   | 149.4      | 150.0                     |
| Yield strength (AISI 1020) | —                     | 351.6 MPa         | 351.6 MPa                  |

The SolidWorks stress result (149.4 MPa) is within **0.4%** of the analytical
hand-calculated value (150.0 MPa) — strong agreement, confirming the FEA
setup (mesh, fixture, load, material) is correct.
